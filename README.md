<div align="center">
  <h1>💰 Finance.ai — Gestão Financeira com IA</h1>
  <p>O <b>Finance.ai</b> é um assistente financeiro completo desenvolvido com o que há de mais moderno no ecossistema Web. O diferencial está na integração com Inteligência Artificial para automação de registros e análise de dados.</p>
</div>

<hr />

<h3>🚀 Diferenciais do Projeto</h3>
<ul>
  <li><b>🤖 Assistente de Importação com IA:</b> Basta subir o PDF da sua fatura e a IA categoriza e registra tudo automaticamente.</li>
  <li><b>📊 Dashboards Dinâmicos:</b> Gráficos de fluxo de caixa e gastos por categoria para visualização clara.</li>
  <li><b>🎯 Gestão de Metas:</b> Planeje seus sonhos com barras de progresso dinâmicas.</li>
  <li><b>🌓 Dark & Light Mode:</b> Interface elegante que se adapta ao seu sistema.</li>
  <li><b>👤 Perfil em Tempo Real:</b> Avatares gerados dinamicamente com degradês baseados no seu nome.</li>
</ul>

<hr />

<h3>🛠 Tech Stack</h3>
<p>Projeto atualizado para 2026 com as tecnologias:</p>
<ul>
  <li><b>Framework:</b> Next.js 15 (App Router)</li>
  <li><b>Linguagem:</b> TypeScript</li>
  <li><b>Estilização:</b> Tailwind CSS v4</li>
  <li><b>Banco de Dados:</b> PostgreSQL (Supabase)</li>
  <li><b>ORM:</b> Prisma</li>
</ul>

<hr />

<h3>📦 Como Instalar e Rodar</h3>

<p>1. Clonar e acessar o repositório:</p>
<pre>
<code>git clone https://github.com/seu-usuario/finance-ai.git
cd finance-ai</code>
</pre>

<p>2. Instalar dependências:</p>
<pre>
<code>npm install</code>
</pre>

<p>3. Configurar Variáveis de Ambiente (.env):</p>
<pre>
<code>DATABASE_URL="sua_url_do_prisma"
DIRECT_URL="sua_url_direta_supabase"
NEXT_PUBLIC_SUPABASE_URL="sua_url_api_supabase"
NEXT_PUBLIC_SUPABASE_ANON_KEY="sua_chave_anon_supabase"
GOOGLE_AI_API_KEY="sua_chave_da_ia"</code>
</pre>

<p>4. Sincronizar Banco e Rodar:</p>
<pre>
<code>npx prisma db push
npm run dev</code>
</pre>
